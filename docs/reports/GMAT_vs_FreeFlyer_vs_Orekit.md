# GMAT vs. FreeFlyer vs. Orekit — Astrodynamics / Mission Analysis Comparison

**Scope:** Capability comparison of three astrodynamics and mission-analysis software suites: NASA Goddard's **GMAT** ([nasa/GMAT](https://github.com/nasa/GMAT)), a.i. solutions' **FreeFlyer** ([a.i. solutions](https://ai-solutions.com/freeflyer-features/)), and CS GROUP's **Orekit** ([CS-SI/Orekit](https://github.com/CS-SI/Orekit)). Coverage: licensing/cost, architecture, propagation, force models, orbit determination, optimization/targeting, scripting & APIs, documentation & samples, and recommended use cases. This is the first (front) section of a multi-part astrodynamics report; subsequent sections cover GNC/ADCS simulators (Basilisk vs. 42, Basilisk vs. NOS3).

**Evidence basis:** Verified against primary sources — official repositories and documentation, not marketing. GMAT: R2026a release ([SourceForge](https://sourceforge.net/projects/gmat/files/GMAT/GMAT-R2026a/)), Apache 2.0 license ([nasa/GMAT](https://github.com/nasa/GMAT)), NASA Software Catalog GSC-19468-1 ([NASA Software](https://software.nasa.gov/software/GSC-19468-1)), user guide ([NASA NTRS](https://ntrs.nasa.gov/api/citations/20080047410/downloads/20080047410.pdf)). FreeFlyer: official feature/help docs ([a.i. solutions](https://ai-solutions.com/freeflyer-features/)) and 2025 GSA contract terms PDF ([GSA Advantage](https://www.gsaadvantage.gov/ref_text/GS07F0743X/GS07F0743X_ai_Solutions_Terms_and_Conditions_PO_0057_16July25.pdf)). Orekit: official API/architecture docs ([orekit.org](https://www.orekit.org/site-orekit-latest/apidocs/index.html), [Propagation](https://www.orekit.org/site-orekit-latest/architecture/propagation.html), [Estimation](https://www.orekit.org/site-orekit-latest/architecture/estimation.html)), GitHub mirror ([CS-SI/Orekit](https://github.com/CS-SI/Orekit)).

## Executive Verdict


| Question                                    | Verdict                                                                                                                                                                                                                    |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| License & cost (no budget)                  | **GMAT** and **Orekit** are free open-source; **FreeFlyer** is commercial with annual maintenance.                                                                                                                         |
| Turn-key GUI / scripting for non-developers | **GMAT** (GUI + script) and **FreeFlyer** (script + viz); **Orekit** is a library (no GUI).                                                                                                                                |
| Orbit propagation breadth & fidelity        | **Orekit** — analytical, semi-analytical (DSST), numerical, TLE, GNSS; strongest library-level breadth. **FreeFlyer** and **GMAT** comparable on numerical force modeling.                                                 |
| Orbit determination (batch + Kalman)        | **Orekit** (batch LS, EKF, UKF, ESKF, multi-satellite) and **GMAT** (BatchEstimator, EKF). **FreeFlyer** supports OD via its measurement/estimation objects.                                                               |
| Trajectory optimization (NLP)               | **FreeFlyer** (built-in Ipopt + NLopt; SNOPT with user license) > **GMAT** (Differential Corrector, VF13ad via separate plugin) > **Orekit** (no general NLP optimizer; user integrates Hipparchus LS or external solver). |
| Scripting language maturity                 | **FreeFlyer** (purpose-built FreeFlyer script) and **GMAT** (own script + Python/MATLAB API). **Orekit** is Java, scripted via Python wrapper (`orekit` PyPI package).                                                     |
| Production / operational heritage           | **FreeFlyer** (250+ missions: ISS ops, JWST, Gateway NRHO, Dream Chaser) and **GMAT** (NASA mission support). **Orekit** widely used in industry/academia as an engine.                                                    |
| International / export status               | **GMAT** (US govt open source) and **Orekit** (Apache 2.0, French/European origin) are freely exportable; **FreeFlyer** is US commercial — export/license status must be vendor-confirmed (see note).                      |


**Bottom line:** Choose by workflow. **Orekit** is the best embeddable engine (free, broad propagation + mature OD, scriptable from Python/Java) for teams building custom tools. **GMAT** is the best free, turn-key desktop mission-analysis application (GUI + scripting + NASA heritage). **FreeFlyer** is the best commercial, operationally-proven, all-in-one platform (mission design through on-orbit operations) for programs that can license it and need vendor support.

## Technical Notes

- **Propagation breadth:** Orekit's distinguishing strength is the breadth of propagator types in one library — analytical (Kepler, Eckstein-Hechler, Brouwer-Lyddane), TLE/SGP4, GNSS navigation-message propagators, the semi-analytical **DSST** (Draper Semi-analytical Satellite Theory), and full numerical integration — all sharing a common `Propagator` interface with event detection ([orekit.org](https://www.orekit.org/site-orekit-latest/architecture/propagation.html)). In the checked sources, Orekit is the one explicitly documented with DSST and GNSS-constellation propagators; GMAT and FreeFlyer are comparably capable on numerical force modeling.
- **Orbit determination:** Orekit ships the most complete estimation toolkit: batch least-squares (Levenberg-Marquardt or Gauss-Newton), an Extended Kalman Filter, an Unscented Kalman Filter, an Extended Semi-analytical Kalman Filter, multi-satellite OD, and initial-orbit-determination methods (Gibbs, Laplace, Gooding, Lambert) ([orekit.org](https://www.orekit.org/site-orekit-latest/architecture/estimation.html)). GMAT provides `BatchEstimatorInv` and an EKF ([NASA Software](https://software.nasa.gov/software/GSC-19468-1)). FreeFlyer supports measurement generation and estimation through its objects.
- **Optimization (the differentiator):** FreeFlyer is the only one of the three to ship **built-in** general-purpose nonlinear optimizers — Ipopt (3.13.2) and NLopt — with SNOPT supported when the user supplies a license/shared library ([a.i. solutions](https://ai-solutions.com/_help_Files/optimization_engines.htm)). GMAT relies on its Differential Corrector and nonlinear constrained optimization, with the VF13ad (HSL/SQP) optimizer available as a **separately licensed plugin** ([ThinkSys](https://www.thinksysinc.com/downloads.html)); SNOPT availability should be verified per GMAT release. Orekit does not ship a general NLP optimizer — its numerical strengths are estimation/least-squares (via Hipparchus) and propagation; for trajectory optimization you integrate an external solver.
- **Form factor matters:** GMAT and FreeFlyer are applications (GUI + scripting + visualization + reporting) — usable by analysts without writing code. Orekit is a library — powerful and embeddable, but there is no GUI; you script it from Java or the Python wrapper. For teams that want a desktop tool, Orekit alone is not sufficient without building (or adopting) a front end.
- **Export / procurement caveat (FreeFlyer):** Some a.i. solutions product listings market FreeFlyer as "ITAR-Free," but a 2025 GSA contract terms-and-conditions PDF for a.i. solutions includes US Munitions List / ITAR export-control language ([GSA PDF](https://www.gsaadvantage.gov/ref_text/GS07F0743X/GS07F0743X_ai_Solutions_Terms_and_Conditions_PO_0057_16July25.pdf)). For non-US procurement, the export status should be confirmed directly with the vendor for the exact license, version, and modules being purchased.

## Recommendations by Use Case


| Use case                                                                  | Recommended                                                                                                   |
| ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Free, turn-key desktop mission analysis (GUI + script)                    | **GMAT**                                                                                                      |
| Commercial, vendor-supported, full mission lifecycle (design → ops)       | **FreeFlyer**                                                                                                 |
| Embeddable astrodynamics engine in a custom tool (Java/Python)            | **Orekit**                                                                                                    |
| Broadest propagation library (analytical + DSST + numerical + TLE + GNSS) | **Orekit**                                                                                                    |
| Mature orbit determination (batch LS, EKF, UKF, multi-satellite)          | **Orekit** (then GMAT)                                                                                        |
| Trajectory optimization with built-in NLP (Ipopt/NLopt/SNOPT)             | **FreeFlyer**                                                                                                 |
| Low-cost trajectory optimization (VF13ad plugin)                          | **GMAT**                                                                                                      |
| Python scripting of astrodynamics                                         | **Orekit** (PyPI wrapper) or GMAT (Python API)                                                                |
| CCSDS ODM/ADM/TDM interoperability                                        | **Orekit**                                                                                                    |
| NASA / US-government program heritage                                     | **GMAT** (and FreeFlyer)                                                                                      |
| International (export-restricted environment)                             | **GMAT** or **Orekit** — open-source/publicly available; still confirm institutional export/procurement rules |
| Education / research / prototyping at no cost                             | **GMAT** or **Orekit**                                                                                        |


---



## Bottom Line

**Orekit** is the best **embeddable engine**: free, Apache-2.0, the broadest propagation and orbit-determination library in the group, and scriptable from Python or Java — ideal for teams building custom astrodynamics services. **GMAT** is the best **free desktop application**: a NASA-maintained, GUI-and-script mission-analysis tool with operational heritage and VF13ad optimization plugin. **FreeFlyer** is the best **commercial, operationally-proven platform**: built-in Ipopt/NLopt optimization, a mature scripting language, 250+ mission heritage (ISS, JWST, Gateway), and vendor support — at a license cost and with export status that must be confirmed for non-US use. For a budget-constrained, internationally deployable workflow, GMAT + Orekit cover most needs; for a supported, end-to-end operational program, FreeFlyer is the strongest single choice.
