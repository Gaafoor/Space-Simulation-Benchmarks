## Implementation Difficulty Notes

- Additional setup overhead compared with Basilisk/GMAT:
  - install `orekit_jpype` Python package;
  - install a JVM (OpenJDK);
  - download `orekit-data.zip`.
- Runtime execution after setup is stable and reproducible.
- No native Orekit sensor-access API was used in this A3 workflow; FOV checks are explicit Python geometry, matching A3 method parity.
